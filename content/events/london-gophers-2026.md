Creating a full Desktop Environment with Go!

Looking at how the Tyde project and FyshOS distribution make it possible to build a complete desktop experience entirely in Go. The talk covers the design, architecture and technical considerations involved, with visual examples of the desktop and its applications, showing how Go is a great fit for this problem and inspiring developers to create native apps in Go.
